# GitHub public repository setup / GitHub 创建仓库

The GitHub connector available in this chat can **write to an existing repository** but cannot create one. To enable uploading the project:

1. Sign in to https://github.com/new as `yunyizhang2202`.
2. Repository name: **two-chat-relay**.
3. Description (optional): `A free Chrome extension for automatic conversation relaying between two AI chat tabs. / Chrome 双 AI 对话自动接力扩展。`
4. Set **Public**.
5. Select **Add a README file** (creates a main branch so connected GitHub tools can write). Do not choose a license or gitignore template; these are included in the project.
6. Click **Create repository**.
7. Return to the ChatGPT conversation with the repository URL. The assistant can then upload this prepared baseline, overwrite the placeholder README, and open research issues through the connected GitHub app.

Do not publish real ChatGPT chat transcripts, profile data, credentials, or files under `local-data/`.
