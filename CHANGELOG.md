# Changelog / 更新记录

## [1.0.0] - 2026-10-14

**Baseline release, not a provider expansion.** / 基线版本，不是跨平台版本。

- Freeze the user-tested v0.13 Chrome ChatGPT-to-ChatGPT implementation.
- Public repository layout, bilingual README, MIT license, developer documents.
- Change `manifest.json` and UI version display to 1.0.0; no relay-engine algorithm changes.
- Keep autonomous/open/manual start, custom or unlimited counts, optional length controls, and delivery verification.
- Record the multi-provider (DeepSeek) exploration as a future task, not a v1.0 feature.

### Previous internal iterations / 内部开发历程

- **v0.1–0.4:** Initial relay and error diagnostics.
- **v0.5–0.9:** New ChatGPT page layouts; send confirmation, Markdown and message integrity.
- **v0.10–0.12:** Autonomous and unrestricted opening; large-count mode; long text/math handling.
- **v0.13:** Simplified user interface and saved settings.

These development notes summarize work done before public release; they are not separately tagged public releases.
